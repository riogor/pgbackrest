# ADBM-3528: custom repository ciphers

[Wiki home](../README.md)

These are branch-specific notes. PR [arenadata/pgbackrest#112](https://github.com/arenadata/pgbackrest/pull/112) targets `2.54-ci`; the inspected head is `b8ce27223`.

## Implementation scope

- Add option/help definitions for additional AES sizes, ARIA, SM4, and GOST.
- Map long identifiers to real OpenSSL names; validate exact allowed strings.
- Support provider fetch plus legacy engine lookup and correct resource ownership.
- Normalize Kuznyechik/Grasshopper aliases for OpenSSL versions.
- Carry actual cipher type through backup/restore/manifest/verify and worker parameters, replacing hard-coded AES-256 assumptions.
- Improve metadata decryption errors and add GOST tests/container setup.

The branch also contains CI/container compatibility updates. Review the complete diff relative to the intended base, rather than assuming short development commit messages explain each feature.
